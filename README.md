# Simple Python Calculator

## Description
A simple calculator built in Python that allows users to perform basic arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division

The program runs in the terminal and continuously allows the user to perform calculations until they choose to exit.

## Features
- Add two numbers
- Subtract two numbers
- Multiply two numbers
- Divide two numbers
- Handles division by zero
- User-friendly menu system

## Technologies Used
- Python 3

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python Calculator.py
